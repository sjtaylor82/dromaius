Your apps

    Install from Google Play

    Type an app name to search Google Play, paste a Google Play link, or enter a package name such as org.mozilla.firefox.

    Actions

      Keyboard help

      Android screens are shown as a web page, so your screen reader's browse mode, quick navigation keys, elements list and say all all work.

      Alt+Home
      Show your apps
      Alt+Left
      Android Back
      Ctrl+L
      Find an app on Google Play: type its name, or paste a link
      Shift+F10 or the Applications key
      More actions for the current item, such as long press
      F5
      Refresh the screen
      Alt+N
      Android notifications
      Enter on an edit field
      Submit, for example run a search

      Long lists show only what fits on the Android screen. Use the "Show more items" button at the end of a list to load more.
